# Security and privacy

This repository is an educational image-comparison baseline, not an identity-verification service. It accepts only local file paths and does not upload images to an external API.

Do not commit real identity documents, personal data, API keys, or test images you are not authorized to use. Prefer synthetic or explicitly licensed samples.

Report security concerns privately through the contact information at [sainesh.com](https://sainesh.com/), not through an issue containing sensitive documents or personal information.
